# 🏡 California Housing Price Prediction

A Machine Learning project focused on predicting median house values in California using real-world housing data.

## 📌 Overview

This project explores the fundamentals of Machine Learning through a regression problem using the California Housing dataset.

The goal is to understand how different housing and demographic features influence property prices and build models capable of predicting median house values.

## 🎯 Objectives

- Understand and explore a real-world dataset.
- Perform Exploratory Data Analysis (EDA).
- Identify relationships between features and housing prices.
- Handle missing values and prepare data for training.
- Apply feature engineering and data preprocessing.
- Train and evaluate regression models.
- Understand the impact of different evaluation metrics.

## 📊 Dataset

The project uses the California Housing dataset, containing information about housing districts in California.

Some important features include:

- `longitude` – Geographic longitude
- `latitude` – Geographic latitude
- `housing_median_age` – Median age of houses
- `total_rooms` – Total number of rooms
- `total_bedrooms` – Total number of bedrooms
- `population` – District population
- `households` – Number of households
- `median_income` – Median household income
- `median_house_value` – Target variable

The regression models can be evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
